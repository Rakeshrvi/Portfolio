# Portfolio Website

## 🚀 Deployment Instructions (IMPORTANT)

This project uses **GitHub Actions** for deployment. To ensure it works correctly:

1. Go to your repository **Settings** > **Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. (Optional) If you see a 404 error, ensure the repository name matches the `base` path in `vite.config.ts` (currently `/Portfolio/`).

---

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
